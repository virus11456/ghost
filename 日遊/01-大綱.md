# 《日遊》小說大綱（草案，待 Frank 確認）

「陰陽帳」三部曲第二部。定案依據：`00-三部曲.md`「《日遊》開書定案」、反轉階梯第 11–15 層；世界觀沿用 `02-世界觀.md`（含「帳外人」），十條鐵律不改。

## 目錄與進度

**進度。** 大綱草案；正文 0 章。卷一排到每章一句；卷二至卷十二先排到卷級（開頭、調查、反轉、揭曉、主線推進），每一卷開寫前再補到每章一句，給 Frank 看過才寫。

**篇幅。** 約 100 萬字，十二卷，每卷 25 章上下，每章 3,000–3,500 字；一卷一案，卷末把主線往前推一格。

**視角。** 卷一跟水安（莊懷安），第三人稱；卷二起水安與水禾（葉禾）輪流當視角，一章跟一個人。周遠不當視角，他坐在當年長衫先生的位置：擺攤、收驚、出主意，不搶徒弟的案子。

## 故事核心

白天的大街上，一個個活人「失魂」了：照常上班、吃飯、說話，行事曆卻從明天起一片空白，銅錢三枚全立，跟周遠一模一樣。收走他們的不是夜裡敲門的東西；日時的伊不敲門，直接走進來，坐上你的椅子。

周遠收了兩個徒弟，一個學葬、一個學封。三個人追著白天的失魂案，從名字市的新櫃台一路查到一本從來不給人看的帳。第四本帳記的是每個人「會怎麼活」。帳上周遠那一頁是空的，可是空頁底下，原本寫著一個他從來沒見過的名字。

## 卷一　白頁（2028 年春）

接《霧川》第 80 章那一夜：廟口的年輕人坐上小板凳。周遠替他卜，三枚全立。讀者會以為作亂的是新的夜遊神（巡街的白曜每夜站在他家門口）；卷末揭開是白天的東西，而且會坐上人的椅子。

| 章 | 章名 | 大綱 |
| --- | --- | --- |
| 1 | 小板凳 | 莊懷安三週睡不著，走過土地廟口被叫住，坐下。周遠問他最近有沒有人坐過他的椅子，他愣住。替他卜，三枚全立，周遠很久沒有說話，只說「明仔載閣來」。他離開時看見一個提紙燈的矮小老人在街角對他點頭。 |
| 2 | 空格 | 懷安的生活：工程師、和媽媽住何媽媽那棟樓三樓。三週前某天中午吃完便當回座，椅子是溫的；從那天起，手機行事曆明天以後一片空白，資訊部說沒有刪除紀錄。他不是失眠，是閉上眼睛想不到任何「明天」。 |
| 3 | 白灰 | 周遠打給小方。小方調出白石里白灰的鑑定報告和彩蛋五徐柏宇的案子；懷安辦公椅腳下有一撮同樣的白灰。纖維仍比對不到。 |
| 4 | 吃早餐 | 拜訪徐柏宇夫婦：他照常上班，只是一天一天活，每晚在明天那格寫「吃早餐」，寫了就有一天，忘了寫就沒有。太太說他不再生氣、也不再期待任何事。 |
| 5 | 何醫師 | 何靜在縣立醫院替懷安做評估：沒有憂鬱、沒有精神病。她說「他不是睡不著，是沒有明天可以睡過去」。 |
| 6 | 三樓 | 何媽媽認得懷安（冬至來還鍋子那個），塞給他一碗湯圓。懷安媽媽在夜市賣滷味，不信這些；懷安不敢跟她說。 |
| 7 | 紙燈 | 懷安每晚都看見那個提紙燈的矮小老人站在他家門口，看一陣子才走。他告訴周遠；周遠的臉沉下來。 |
| 8 | 巡街 | 周遠夜裡在巷口等白曜。白曜不理他，只說「借過」。周遠擋住路，白曜看他的頭髮，說「你毋是三界外的，你是帳外的」。 |
| 9 | 三本帳 | 白曜不情願地講三本帳：功過簿、生死簿、名字；三界靠三本帳互相牽制。懷安三本都還在，「啥物攏無少」。周遠問那他少了什麼，白曜不答。 |
| 10 | 跟蹤 | 讀者與懷安都懷疑白曜：他是夜遊神，他每夜站在失魂者門口。周遠和懷安跟蹤他走遍縣城，他一戶一戶看門、在燈籠紙上點一個點。 |
| 11 | 九戶 | 周遠搶下燈籠，燈籠紙內側點了九個點，九個地址。九戶都有人「明天以後空白」，都在三週前左右，都在某個中午。 |
| 12 | 正午 | 九戶的共同點：事發都在正午前後，都在自己的椅子上被坐過。周遠想起阿婆說過：日時嘛有物件咧行，伊毋敲門。 |
| 13 | 點算 | 白曜被逼急了才說：他每夜奉命點算「白頁」的人家，點完的數字天亮前燒上去；「收的毋是阮巡夜的。日時的代誌，我管袂著」。巡夜司被降成點算的人。 |
| 14 | 等 | 周遠和懷安在懷安的辦公室等正午。周遠什麼都看不見；懷安卻看見一個穿白衫、戴白帽、拿小簿子的人走進來，坐上隔壁同事的椅子。 |
| 15 | 袂使出手 | 懷安要衝過去，周遠拉住他：先生不得替任何一界出手。白衣人起身離開，椅腳一撮白灰。隔天同事的行事曆空了。懷安第一次對周遠吼。 |
| 16 | 看得見 | 為什麼懷安看得見、周遠看不見？白曜說懷安「被收了一擺，眼睛就開矣」；周遠是帳外人卻看不見，因為他的空是在夜裡被拿的。 |
| 17 | 記得 | 林依、沈言從海尾來；沈言給懷安看「記得」筆記本：每天打一個勾，十幾年沒斷。懷安學徐柏宇，在明天那格寫字，也開始一格一格打勾。 |
| 18 | 葬袂落 | 周遠試著找方法：失魂不是死，不能葬；身上沒有東西，不能封。他翻陳守一的手記，沒有一頁寫過這種事。 |
| 19 | 第二个 | 同事的媽媽來廟口求周遠，周遠只能教她寫明天。懷安看著周遠收她五十塊，不懂。周遠說：「我袂當共伊的命提轉來。我干焦會當陪伊等。」 |
| 20 | 椅仔 | 正午，周遠攤子的小板凳上出現一撮白灰；有東西坐過，什麼都沒收走。周遠是空頁，它找不到東西可收。懷安看見白衣人起身時，低頭在小簿子上劃了一筆。 |
| 21 | 朱紅 | 懷安抄下白衣人小簿子封面上的一個小章：朱紅，比小指甲還小。林依認得：跟仁濟那個女人名片上的一樣（彩蛋四）。名片還壓在海尾的收銀機底下。 |
| 22 | 地址 | 名片上的地址是縣城舊市區一條巷子。周遠去了，是一間空的老店面，門口掃得很乾淨。他沒有進去：「現在進去，就欠伊一擺。」 |
| 23 | 拜師 | 懷安要學。周遠說他不是先生，給他看掌心的「照」。懷安說：「你袂當共我的命提轉來，按呢我家己學。」 |
| 24 | 水安 | 石崗鎮口三座墳前，周遠照派詩替他改名「水安」（照字之後是水）。老闆娘不在了，周遠自己倒三杯茶。 |
| 25 | 明仔載 | 水安在明天那格寫「去廟口幫師父擺攤」。正午，他坐在周遠的攤子旁，看見街對面一個白衣人坐上公車站的長椅，低頭寫字。卷一完。 |
