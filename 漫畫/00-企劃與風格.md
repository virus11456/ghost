# 《霧川》漫畫版：卷一〈沒吃藥〉企劃與風格設定

## 一、企劃

| 項目 | 內容 |
| --- | --- |
| 作品 | 《霧川》漫畫版，改編自同名小說 |
| 本冊 | 單行本第一集＝小說卷一〈沒吃藥〉（第 1–8 章） |
| 類型 | 台灣靈異懸疑，雙時間線（2026 今線／1931 舊線） |
| 讀者 | 15 歲以上；喜歡懸疑、民俗恐怖、慢燒氛圍的讀者 |
| 格式 | 日式右翻黑白漫畫，單色特別色一色（褪紅）；B6 單行本 |
| 篇幅 | 5 話，約 190 頁＋封面、扉頁、卷末附錄 |
| 一句話 | 一個小鎮三百人一夜消失，查案的刑警每晚夢見自己是九十五年前的陰陽學徒。 |

### 分話

| 話 | 標題 | 收錄小說 | 頁數 | 話末畫面 |
| --- | --- | --- | --- | --- |
| 第 1 話 | 空鎮 | 第 1、2 章 | 44 | 黑掉的手機螢幕裡，周遠的倒影慢半拍才移開眼睛 |
| 第 2 話 | 鎮符 | 第 3 章、第 4 章（到月娥回頭為止） | 40 | 月娥只轉過頭：「你剛剛，有回頭嗎？」 |
| 第 3 話 | 監視器 | 第 5 章 | 32 | 監視器畫面裡，周遠自己毫不猶豫走向她：他一眼就看見了 |
| 第 4 話 | 行屍 | 第 4 章結尾、第 6、7 章 | 42 | 周遠的拳頭停在門板前一公分，敲不出第三下 |
| 第 5 話 | 我的錯 | 第 8 章 | 32 | 左右對頁：2026 年門縫裡的林依、1931 年泥地上的小滿，同一句「全部都是我的錯」 |

小說刻意把章尾寫淡；漫畫每一話的最後一頁一定要有一個讓人想翻下一話的畫面。小說裡安靜的段落（澆薄荷、吃鹹粥、魚缸）改成**無對白的喘息頁**，一話至少一次。

## 二、整體風格

**一句話：** 霧氣、留白、不給正臉。恐怖來自「太整齊」與「看不見」，不靠血腥。

### 兩條時間線的視覺區分

| | 今線 2026 | 舊線 1931 |
| --- | --- | --- |
| 線條 | 細而穩的鋼筆線，乾淨的建築與機械 | 毛筆線，筆觸粗細變化大，邊緣有飛白 |
| 色調 | 冷灰，網點為主，大面積淺灰「霧」 | 暖墨色水墨暈染，像泛黃的紙 |
| 分格框 | 直角、細框、規則 | 毛筆框，略歪，角落有墨漬 |
| 特別色 | 只用一種褪紅，見下 | 同一種褪紅 |
| 轉場 | 跨頁或整頁黑底白字標「一九三一年，霧川渡。」 | 回今線時用一格純白空格當「醒來」 |

### 特別色：褪紅

全書唯一的顏色。只給下列東西用，其他一律黑白：
- 鎮符的紅布包（1931）
- 林依藥瓶瓶底的「和」字（第一次出現時）
- 月娥、沈言被附身時的嘴唇（只在笑的那一格）
- 監視器的紅色錄影燈

### 恐怖的畫法規則

1. **前四話不畫夜遊神的正臉。** 只畫背影、側臉、轉過來一半、眼睛反光的白點、過寬的嘴角。第一次正面要留到第二集的鏡中人。
2. **「太整齊」比「太可怕」更恐怖。** 跳舞的人群用重複的同一個姿勢、完全對齊的格線構圖。
3. **拖鞋、凹痕、紅燈** 是三個反覆出現的小物，構圖上給它們特寫，但不加效果線、不加強調字。
4. **留白就是霧。** 遠景大量留白、淡網點，人物從霧裡浮出。

### 字體與排版

| 類別 | 字體 | 說明 |
| --- | --- | --- |
| 對白 | 中黑體 | 一般對白框 |
| 旁白 | 明體，方框 | 今線旁白用直角框；舊線用毛筆框 |
| 台語台詞 | 台語漢字，旁邊小字附華語 | 例：「攏是我的毋著」旁附〔都是我的錯〕 |
| 文件（筆錄、報案錄音、時間碼） | 等寬字體，無框，直接壓在畫面上 | 監視器時間碼用黃白色等寬字放在畫面左上 |
| 被附身時的聲音 | 細明體，對白框邊緣抖動 | 疊在一起的多人聲音用重疊的對白框 |
| 狀聲詞 | 手寫 | 叩、啪、砰、噹、嗡、喀 |

**繁體中文全部後製手動排字。** 生圖時一律要求畫面「no text, no letters」，留出對白框位置。

## 五、生圖 prompt 的寫法

分鏡檔裡的 prompt 用大括號當代號，例如 `{STYLE-NOW}`、`{ZHOU}`、`{TEMPLE-SQUARE}`，生圖時把大括號整段換成本檔對應的英文描述（風格碼、角色碼、場景碼）。

每一格的 prompt 照這個順序組：

```
[風格碼], [鏡頭與構圖], [場景碼的描述], [角色碼], [動作與表情], [光線與氣氛], no text, no letters, empty speech bubble space at [位置]
```

**風格碼（今線）**
```
STYLE-NOW: black and white seinen manga panel, clean fine pen lines, screentone shading, cool grey tones, heavy negative space suggesting mist, restrained realistic proportions, cinematic framing, Taiwanese setting
```

**風格碼（舊線）**
```
STYLE-1931: black and white manga panel rendered in sepia ink wash, expressive brush linework with dry-brush edges, aged paper texture, soft ink bleeding, 1931 rural Taiwan, cinematic framing
```

**特別色**（需要褪紅的格子，加在最後）
```
monochrome except for a single faded rose-red accent on [物件]
```

**通用負面提示**（支援的工具加上）
```
text, letters, watermark, signature, gore, blood splatter, extra fingers, distorted hands, modern objects in 1931 scenes, color (except the specified red accent)
```

**提醒：** 不要在 prompt 裡寫任何在世漫畫家或畫師的名字；風格一律用上面的描述語言。

## 六、分鏡檔案

**直接複製用的版本在 `漫畫/展開版/`**：裡面每一格的 Prompt 已經把 {代號} 全部換成完整英文，給生圖 AI 直接貼上即可。各話檔頭另外定義的新代號（例如監視器畫面、配角、場景），以該話的定義為準。改了分鏡或代號後，執行 `python3 tools/expand_manga.py` 重新產生。


| 檔案 | 內容 |
| --- | --- |
| `第01話-空鎮.md` | 44 頁 |
| `第02話-鎮符.md` | 40 頁 |
| `第03話-監視器.md` | 32 頁 |
| `第04話-行屍.md` | 42 頁 |
| `第05話-我的錯.md` | 32 頁 |

每一頁的格式（範例）：

```
### P03（版型：上大下二）
**格 1**（上半頁，橫長）
- 畫面：霧中的主街，一台藍色小貨車停在雜貨店前，雨刷在動。
- Prompt：{STYLE-NOW}, wide establishing shot, {WUCHUAN-TOWN}, a small blue delivery truck parked in front of a half-closed grocery store shutter, windshield wipers moving, thick mist swallowing the street, no people, no text, no letters, empty caption space at top right
- 文字：〔旁白，右上方框〕霧川鎮在山坳裡。
**格 2**（下左）
- ……
```

右翻漫畫：同一頁內格子的閱讀順序是「右上 → 左上 → 右下 → 左下」，分鏡檔裡的格號已照閱讀順序排好。
